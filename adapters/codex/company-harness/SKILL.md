# Company Harness

Read `registry/company-harness.yml` and the matching file under `skills/` before material work.

Start with `company-work-packet`. Use `customer-evidence-research` for research, `company-code-delivery` for code, `company-ui-artifact` for application interfaces, `company-dashboard` for dashboards, and `company-artifact-review` before presenting work as complete.

Treat `observe`, `prepare`, `commit`, and `emit` as separate authority levels. Default to `prepare`. Do not infer access, approval, cost, latency, or an external action from a user request alone.
